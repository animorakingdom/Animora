Installing Fabric

Animora Kingdom runs on Fabric, a light and fast mod loader. You need to install it before adding the mods.

  1. Download the Fabric Installer

    Go to the official Fabric website and download the universal installer (.jar).

  2. Have Minecraft 1.21.11

    Open the official launcher and run version 1.21.11 at least once before installing.

  3. Run the installer

    Open the .jar, select version 1.21.11, check 'Create profile' and click Install.

  4. Select the Fabric profile

    In the launcher, choose the 'fabric-loader-1.21.11' profile before playing.
