How to install Animals Craft

In a few steps you install the full modpack. Datapacks (like Spawn Animations and Better Babies) go in your world's 'datapacks' folder.

  1. 1. Install Fabric

    Follow the Fabric page guide to install the loader on Minecraft 1.21.11.

    Go to the Fabric guide

  2. 2. Open the mods folder

    Press Windows + R on your keyboard. A small 'Run' window will open. Type: %appdata%\.minecraft\mods and press Enter. This will open the mods folder directly. If it doesn't exist yet, create a new folder named 'mods' inside the .minecraft folder.

  3. 3. Download and add the mods

    Download the mods from the list (all version 1.21.11 / Fabric) and put the .jar files into the 'mods' folder.

    See mods list

  4. 4. Play!

    Open the launcher, select the Fabric profile and click play. Enjoy Animals Craft!
